# Segú - Web Project

## Structure
This project follows a specific scaffolding structure:

- **Root**: `index.html` (Entry point, redirects to Home)
- **Global Resources**:
  - `global.css`: Global variables, color palette, typography, and resets.
  - `global.js`: Global scripts.
- **Screens**:
  - `screens/home/`: Contains the Home page logic.
    - `home.html`
    - `home.css`
    - `home.js`
- **Assets**:
  - `assets/images/`: Image resources.

## Technologies
- HTML5
- CSS3 (Variables, Flexbox, Grid)
- Vanilla JavaScript

## Design System

### Color Palette (60-30-10 Rule)
We adhere to the **60-30-10 rule** to maintain a balanced and professional aesthetic:
- **30% Primary Color**: Deep Blue (`#01263D`)
  - Used for: Headers, text, strong structural elements.
  - Scale: 100-900 for depth.
- **10% Secondary Color**: Soft Lime (`#C1D789`)
  - Used for: Accents, Call-to-Actions (CTAs), highlights.
  - Scale: 100-900.
- **60% Neutral**: White/Grays
  - Used for: Backgrounds, negative space.

### Typography
Selected for readability and modern professional appeal:
- **Headings**: **Open Sans** (Google Fonts)
- **Body**: **Roboto** (Google Fonts) - Chosen to complement Open Sans with excellent readability.

### Gradients
1. **Corporate**: Deep Blue gradient.
2. **Growth**: Blue to Green transition.
3. **Warm**: Soft Lime variations.

### Accessibility
- Ensures WCAG AA/AAA compliance for contrast ratios.
